# 🩺 Medical Product Analyzer

A powerful AI-based web tool that analyzes images of medical products (tablets, strips, labels) and extracts critical information such as name, benefits, side effects, usage instructions, and expiry details using Google's Gemini API.

---

## 🚀 Features

- 📸 Upload an image of any medicine label or tablet strip
- 🧠 AI-driven analysis using Gemini 2.5
- 📄 Extracts:
  - Product Name
  - Benefits
  - Potential Side Effects
  - How & When to Use
  - Important Considerations
  - Manufacturing & Expiry Dates
- 📱 Fully responsive UI (works on desktop, tablet & mobile)
- 🌐 Built with HTML, TailwindCSS, and JavaScript
